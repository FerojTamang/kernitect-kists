KISTS Phase 6C — Real 360° Manual Handling Scenario

Prerequisite already completed by Feroj:
client/src/assets/scenarios/manual-handling/manual-handling-warehouse.jpg

1. From the KISTS repository root install the 360 viewer dependencies:
   npm.cmd install --workspace client @photo-sphere-viewer/core@5.15.1 @photo-sphere-viewer/markers-plugin@5.15.1

2. Apply the files from this patch archive to the repository root.
   IMPORTANT: this patch does NOT include or overwrite manual-handling-warehouse.jpg.

3. Refresh the scenario database resource reference without resetting data:
   npm.cmd run db:seed

4. Run checks:
   npm.cmd run typecheck
   npm.cmd run lint
   npm.cmd run format
   npm.cmd run format:check
   npm.cmd run build
   npm.cmd run test:frontend
   git diff --check

5. Open KISTS:
   My Training -> Manual Handling -> Scenario

Expected Phase 6C behaviour:
- genuine spherical/equirectangular 360-degree viewer
- drag left/right/up/down and fully around
- zoom/full-screen controls
- five database-driven Manual Handling hotspots at yaw/pitch coordinates
- clicking a hotspot opens the existing safety decision panel
- correct answers still persist in PostgreSQL
- completed hotspots change to green check marks
- 5/5 completion still leads to the Phase 7 Final Assessment hand-off

Do not use db:reset for this change.
